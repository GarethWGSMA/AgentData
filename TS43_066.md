## 5.1.1 SMSoIP Entitlement Status

- Parameter Name: EntitlementStatus
- Presence: Mandatory

This parameter indicates the overall status of the SMSoIP entitlement, stating if the service can be offered on the device, and if it can be activated or not by the end-user.

The different values for the SMSoIP entitlement status are provided in Table 24.

| SMSoIP Entitlement parameter | Type | Values | Description |
| --- | --- | --- | --- |
| EntitlementStatus<br>(Mandatory) | Integer | 0 - DISABLED | SMSoIP service allowed, but not yet provisioned and activated on the network side |
| EntitlementStatus<br>(Mandatory) | Integer | 1 - ENABLED | SMSoIP service allowed, provisioned, and activated on the network side |
| EntitlementStatus<br>(Mandatory) | Integer | 2 - INCOMPATIBLE | SMSoIP service cannot be offered |
| EntitlementStatus<br>(Mandatory) | Integer | 3 - PROVISIONING | SMSoIP service being provisioned on the network side |

Table 24. Entitlement Parameter - SMSoIP Overall Status
