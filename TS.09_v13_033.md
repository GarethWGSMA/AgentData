## 2.7.3 WLAN in conjunction with GSM or WCDMA Talk Time Parameters

The WLAN, GAN and GSM configuration parameters are the same as defined in the WLAN Standby Time test section 3.8. In addition the following network GAN parameters apply:

| Parameter | Recommended Value | Comment |
| --- | --- | --- |
| RTP/UDP Packet Sample Size | 20 ms |  |
| Channel Mode | Full Rate AMR |  |
| Speech Codec Rate | 12.2 Kbit/s |  |
| WLAN UE TX Level | 10 dBm |  |
| Call | 40/40/20 voice activity pattern | Refer to initial configuration in section 6.1 |

: Additional GAN network parameters for VoIP
