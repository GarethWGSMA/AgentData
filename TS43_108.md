## 6.6.3 ManageSubscription Response Example

Table 58 presents an example for the ManageSubscription response in XML format to a Companion or Primary ODSA application. This response indicates that the end-user is to be sent to an ODSA portal web server.

| <?xml version="1.0"?><br><wap-provisioningdoc version="1.1"><br>    <characteristic type="VERS"<br>       <parm name="version" value="1"/><br>       <parm name="validity" value="172800"/><br>    </characteristic><br><br>    <characteristic type="TOKEN"><br>      <parm name="token" value="ASH127AHHA88SF"/><br>    </characteristic><br><br>    <characteristic type="APPLICATION"><br>      <parm name="AppID" value="ap2006"/><br>      <parm name="SubscriptionServiceURL" value="http://www.MNO.org/CDSubs"/><br>      <parm name="SubscriptionServiceUserData" value="imsi=XX&amp;msisdn=XX"/><br>      <parm name="SubscriptionResult" value="1"/>  <!-- continue to websheet  --><br>      <parm name="OperationResult" value="1"/><br>    </characteristic><br></wap-provisioningdoc> |
| --- |

Table 58. Example of a ManageSubscription ODSA Response in XML format to send user to ODSA portal.
