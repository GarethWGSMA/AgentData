## 12.2 Option 2: Satellite simulator not available

Initial configuration

Place the terminal in a stationary position. If the test is performed outside ensure the internal GPS antenna has unobstructed line of sight to clear sky conditions. If the test is performed inside then it must be ensured that the GPS signal is provided to the terminal (for example using a cable connection or use of a GPS antenna repeater).

Test procedure

1. The default GPS Tracking periodicity shall be used. The value used, if known, shall be noted in the test data for GPS tracking. If adaptive tracking is used then it shall be noted in the test data for GPS tracking.
1. Navigate to and enable the bundled mapping application. Should no bundled mapping application be available, or should the bundled mapping application not be suitable, any application that can run in the background, without display view and on 1Hz, could be used
1. Wait until it is clear that terminal has a valid positioning fix and wait for the backlight to extinguish.
1. Start the measurement, run the measurement for ten minutes and note the average current consumption over this period.
1. Complete the test data for GPS tracking
