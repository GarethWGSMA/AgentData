## 2.9.4 JSON-Based Configuration Document

The JSON object value returned as part of an entitlement configuration request for the entitlements of VoWiFi, Voice-over-Cellular and SMSoIP is presented in Table 11. Each characteristic type of the XML document is mapped to the JSON document as a structured object with several fields.

For the Companion and Primary ODSA applications, refer to 6.6 for a description of the JSON-based document defined for each operation of those applications.

| {<br>    "Vers" : {<br>        "version" : "X",<br>        "validity" : "Y"<br>    },<br>    "Token" : {              // Optional<br>        "token" : "U",<br>        "validity" : "V"<br>    },<br>    "ap2004": {            // VoWiFi Entitlement settings<br>        "EntitlementStatus" : "X",<br>        "ServiceFlow_URL" : "X",<br>        "ServiceFlow_ UserData" : "X",<br>        "MessageForIncompatible" : "X",<br>        "AddrStatus" : "X",<br>        "TC_Status" : "X",<br>        "ProvStatus" : "X"<br>    },<br>    "ap2003" : {            // Voice-over-Cellular Entitlement settings<br>        "VoiceOverCellularEntitleInfo" : [{<br>             "RATVoiceEntitleInfoDetails" : {<br>                "AccessType" : "1", //4G<br>                "HomeRoamingNWType" : "1", //Home & Roaming networks<br>                "EntitlementStatus" : "1"  //Enabled<br>             }<br>           },{<br>              "RATVoiceEntitleInfoDetails" : {<br>                "AccessType" : "2", //5G<br>                "HomeRoamingNWType" : "2", //Home Network<br>                "EntitlementStatus" : "1", //Enabled<br>                "NetworkVoiceIRATCapablity" : "EPS-Fallback"<br>             }<br>           },{<br>              "RATVoiceEntitleInfoDetails" : {<br>                "AccessType" : "2", //5G<br>                "HomeRoamingNWType" : "3", //Roaming Network<br>                "EntitlementStatus" : "2", //Incompatible<br>                "MessageForIncompatible" : "Z"<br>             }<br>        }]<br>    },<br>        "ap2005" : {           // SMSoIP Entitlement settings<br>        "EntitlementStatus" : "X"<br>    }<br>} |
