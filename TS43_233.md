## 14.1.6.2 Subscriber Device Information

Parameters in the response are described in Table 126.

| GetSubscriberDeviceInfo response parameters | Type | Values | Description |
| --- | --- | --- | --- |
| MSISDN | String | Any string value | E.164 formatted phone number.<br>It is possible to provide the base64 encoding of the value by preceding it with encodedValue= |
| IMSI<br>(Optional) | String | A 15 digits (max) string | International Mobile Subscriber Identity as per ITU E.212 or 3GPP TS 23.003 standards. |
