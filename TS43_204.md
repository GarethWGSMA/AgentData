## 11.5.1 Initial Requests

Initial request can use GET or POST methods.

Table 98 presents a sample HTTP GET request for DCB entitlement with the parameters located in the HTTP query string.

| GET ? terminal_id = 013787006099944&<br>token = es7w1erXjh%2FEC%2FP8BV44SBmVipg&<br>terminal_vendor = TVENDOR&<br>terminal_model = TMODEL&<br>terminal_sw_version = TSWVERS&<br>entitlement_version = ENTVERS&<br>app = ap2012&<br>store_vendor=STORE_VEND&<br>store_user_id=<STORE_USR>&<br>vers = 1 HTTP/1.1<br><br>Host: entitlement.telco.net:9014<br>User-Agent: PRD-TS43 TVENDOR/TMODEL IMS-Entitlement/TSWVERS OS-Android/8.0<br>Accept: text/html,application/xhtml+xml,application/xml;q=0.9,*/*;q=0.8<br>Accept-Language: en-US,en;q=0.5<br>Accept-Encoding: gzip, deflate<br>Connection: keep-alive |
