## 11.1.2 DCB T&C Status

These are the parameters name and presence required in DCB for T&C status.

- TC_Status: Mandatory
- TC_Operation: Optional

In some regions, end-users must agree to the Terms and Conditions (T&C) of the DCB service before being allowed to use it. This entitlement parameter indicates if that condition must be met before offering the DCB service.

Also, if acceptance of the DCB’s T&C is indeed needed from the end-user, this parameter indicates the state of the “T&C acceptance” process.

The different values for the DCB T&C status are provided in Table 92.

| DCB Entitlement parameter | Type | Values | Description |
| --- | --- | --- | --- |
| TC_Status<br>(Mandatory) | Integer | 0 - NOT AVAILABLE | T&C have not yet been accepted by the end-user |
| TC_Status<br>(Mandatory) | Integer | 1 - AVAILABLE | T&C have been accepted by the end-user |
| TC_Status<br>(Mandatory) | Integer | 2 - NOT REQUIRED | T&C acceptance is not required to offer VoWiFi service |
| TC_Status<br>(Mandatory) | Integer | 3 - IN PROGRESS | T&C capture and acceptance is on-going |
| TC_Operation<br>(Conditional) | Integer | Returned only if TC_Status is 0 - NOT AVAILABLE | Returned only if TC_Status is 0 - NOT AVAILABLE |
| TC_Operation<br>(Conditional) | Integer | 1 – WEBSHEET_IS_PREFERED | T&C capture and acceptance through web portal is the preferred option for the carrier.<br>If device doesn’t support this, it will take the other one (MSG), if available. |
| TC_Operation<br>(Conditional) | Integer | 2 – MSG_IS_PREFERED | T&C capture and acceptance through client is the preferred option for the carrier.<br>If device doesn’t support this, it will take the other one (WEBSHEET), if available. |

Table 92. Entitlement Parameter - DCB T&C Status and Operation
