## 14.1.1 Device App authentication Request Parameters

For device App authentication, devices require additional parameters in the HTTP requests, outside of the ones described in 2.3 and 6.2. Table 116 presents the new parameters and their associated operations.

| New GET parameters app authentication | Type | Values | Description |
| --- | --- | --- | --- |
| operation | String | AcquireOperatorToken | Indicates the operation requested by the TS.43 client |
| access_token<br>(optional) | String | Used by the AcquireOperatorToken and AcquireTemporaryToken operation to verify the requesting application.<br>This parameter is also used when consuming the OperatorToken through any of the operations described in section 14.1.6 | Used by the AcquireOperatorToken and AcquireTemporaryToken operation to verify the requesting application.<br>This parameter is also used when consuming the OperatorToken through any of the operations described in section 14.1.6 |
| access_token<br>(optional) | String | Any string value | Token based on pre-shared security information |
| client_id<br>(conditional) | String | Used by the AcquireOperatorToken operation to identify the requesting application. Used in combination with the TemporaryToken serving as secret for authentication.<br>This parameter will be mandatory for validateOperationToken in case the user wants to validate client_id for a specific token. It could be used in combination (for validation) with scope parameter. | Used by the AcquireOperatorToken operation to identify the requesting application. Used in combination with the TemporaryToken serving as secret for authentication.<br>This parameter will be mandatory for validateOperationToken in case the user wants to validate client_id for a specific token. It could be used in combination (for validation) with scope parameter. |
| client_id<br>(conditional) | String | Any string value | Identifier of the requesting application |
| scope<br>(conditional) | String | Used by the AcquireOperatorToken operation to indicate the access privileges being requested for OperatorToken. Used in combination with client_id.<br>This parameter will be mandatory for validateOperationToken in case the user wants to validate scope for a specific token. It could be used in combination (for validation) with client_id parameter. | Used by the AcquireOperatorToken operation to indicate the access privileges being requested for OperatorToken. Used in combination with client_id.<br>This parameter will be mandatory for validateOperationToken in case the user wants to validate scope for a specific token. It could be used in combination (for validation) with client_id parameter. |
| scope<br>(conditional) | String | Any string value | Indicates which access privileges are being requested for OperatorToken |
| msisdn<br>(Conditional) | String | Used by the VerifyPhoneNumber operation to compare this value with the one mapped to the token generated during the Authentication process. | Used by the VerifyPhoneNumber operation to compare this value with the one mapped to the token generated during the Authentication process. |
| msisdn<br>(Conditional) | String | MSISDN of the subscription in E.164 format. | MSISDN to verify. |
