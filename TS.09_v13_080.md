## 9 Streaming Content Test

Since the used bearer and transmit power of the terminal is affecting the streaming power consumption, it is recommended that a system simulator is used. In case the system simulator is not connected to the internet, the streaming server provides the required streaming files that can be downloaded and installed on the system simulator.

The default setting for the appropriate bearer (see section 7) shall be used. When supported, WCDMA or E-UTRA shall be used.
