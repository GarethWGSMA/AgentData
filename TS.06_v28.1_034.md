## 16 Type Allocation Holder Responsibilities

Within the context of this document Type Allocation Holders have the following responsibilities.

- Comply with the relevant Type Allocation requirements.
- Complete all information requested by GSMA with regards to company registration and TAC requests.
- Ensure IMEI are secure and have integrity.
- Consider recommendations to increment SVN for new software in ME.
- Apply to relevant bodies for Test IMEI when required.
- Gain permission from operators to use test ME where required.
