## 11.5 BT data transfer in idle

The objective of this test is to measure specifically Bluetooth power efficiency.

The test parameters are:

- Cellular mode: idle, as per the already specified idle mode scenario
- BT node to terminal distance: 1 meter, or use artificial attenuation to achieve the same result
- File to transfer: GSMA MP3 reference file (as per Music Playback scenario)

The results are to be specified as MB Transfer within battery life (as per other data transfer tests).
