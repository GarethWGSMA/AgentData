## 14.1.6.1 Operator Token Validation

Parameters in the response are described in Table 123.

| ValidateOperatorToken response parameters | Type | Values | Description |
| --- | --- | --- | --- |
| OperatorTokenValidity | Integer | Indicates if the parameters (client_id and/or scope) are valid ones for the specific operator token in the request. | Indicates if the parameters (client_id and/or scope) are valid ones for the specific operator token in the request. |
| OperatorTokenValidity | Integer | 0 – NOT VALID | The operator token provided is not a valid one |
| OperatorTokenValidity | Integer | 1 – VALID | The operator token provided is valid one |
| OperatorTokenValidatedParams<br>(Optional) | String | Comma-separated list with parameters validated. | List the parameters that have been validated for the operator_token. |

Table 123. Response parameters for ValidateOperatorToken operation
