## 3.7.2 Current Consumption

The following procedure shall be used to measure the average current drain of the USB data modem:

1. Connect the USB data modem with the USB port as described in section 3
1. Activate the USB data modem
1. Wait 3 minutes after activation for the USB data modem boot processes to be completed.
1. Place the USB data modem into the appropriate test configuration and wait for 30 s.
1. While the USB data modem is still in the test configuration record the current samples:
Over a continuous 10 minute period for connected mode operations
Calculate the average current drain (Idedicated) from the measured samples.
Record the volume of data transferred in the 10 minute period.
