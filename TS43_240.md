## 15.1.1 SatMode Entitlement Status

- Parameter Name: EntitlementStatus
- Presence: Mandatory

This parameter indicates the overall status of the SatMode entitlement, stating if the service can be offered on the device, and if it can be activated or not by the end-user.

The different values for the SatMode entitlement status are provided in Table 136.

| SatMode Entitlement parameter | Type | Values | Description |
| --- | --- | --- | --- |
| EntitlementStatus<br>(Mandatory) | Integer | 0 - DISABLED | SatMode allowed, but not yet provisioned and activated on the network. Device is redirected to webview using ServiceFlow_URL |
| EntitlementStatus<br>(Mandatory) | Integer | 1 - ENABLED | SatMode service allowed, provisioned and activated on the network |
| EntitlementStatus<br>(Mandatory) | Integer | 2 - INCOMPATIBLE | SatMode cannot be offered for network or device |
| EntitlementStatus<br>(Mandatory) | Integer | 3 - PROVISIONING | SatMode is being provisioned on the network |

Table 136. Entitlement Parameter - SatMode Overall Status
