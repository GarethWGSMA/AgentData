## 11.1 Common Parameters

| Parameter | Value |
| --- | --- |
| Radio environment | The interface tested shall be the only Bluetooth connection in the test area.<br>No other radio should transmit in the 2.4 GHz band (e.g. WLAN) |
| Distance (Phone to BT device) | 10 centimetres |
| Power Class of the BT device | To be stated in the test report |
| Enhanced Data Rate (EDR) | ON |
| Sniff interval | 0x800 (about 1.28 s) |
| Sniff Attempt parameter | 8 |
| Sniff Timeout parameter | 8 |
