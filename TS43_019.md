## 2.3 HTTP GET method Parameters.

Entitlement use cases can also define its own set of request parameters. Refer to 6.2 for the parameters associated with the Companion and Primary ODSA use cases.

Table 5 presents a sample HTTP GET request for VoWiFi entitlement with the parameters located in the HTTP query string.

| GET ? terminal_id = 013787006099944&<br>token = es7w1erXjh%2FEC%2FP8BV44SBmVipg&<br>terminal_vendor = TVENDOR&<br>terminal_model = TMODEL&<br>terminal_sw_version = TSWVERS&<br>entitlement_version = ENTVERS&<br>app = ap2004&<br>GID1 = 123D&<br>vers = 1 HTTP/1.1<br><br>Host: entitlement.telco.net:9014<br>User-Agent: PRD-TS43 TVENDOR/TMODEL IMS-Entitlement/TSWVERS OS-Android/8.0<br>Accept: text/html,application/xhtml+xml,application/xml;q=0.9,*/*;q=0.8<br>Accept-Language: en-US,en;q=0.5<br>Accept-Encoding: gzip, deflate<br>Connection: keep-alive |
