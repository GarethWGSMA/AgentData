## 6.5.5 AcquireConfiguration Operation Configuration Parameters

The CompanionConfiguration and PrimaryConfiguration structures have the parameters listed in Table 43.

| “AcquireConfiguration” configuration parameters | Type | Values | Description |
| --- | --- | --- | --- |
| ICCID<br>(Conditional) | String | a valid ICCID, encoded as a 10-octet string | Integrated Circuit Card Identification - Identifier of the eSIM profile on the device’s eSIM.<br>Present if an eSIM profile exists for the device. |
| CompanionDeviceService<br>(Mandatory for a Companion Configuration) | String | SharedNumber | Indicates that the configuration is for the “Shared Number” service (where the device carries the same MSISDN as the primary one) |
| CompanionDeviceService<br>(Mandatory for a Companion Configuration) | String | DiffNumber | Indicates that the configuration is for the “Different Number” service (where the device carries a different MSISDN from the primary one but is assigned to the same subscriber.) |
| CompanionDeviceService<br>(Mandatory for a Companion Configuration) | String | FamilyNumber | Indicates that the configuration is for the “Family Number” service (where the device carries a different MSISDN from the primary one and the MSISDN can be assigned to another individual or subscriber.) |
| SecondaryICCID<br>(Conditional) | Integer | 1 – True | This field is only present to indicate if the Primary Configuration was designated as a Secondary ICCID by the ECS |
| ServiceStatus<br>(Mandatory) | Integer | 1 to 4 | Refer to Table 42 for a description of the allowed values for ServiceStatus. |
| PollingInterval<br>(Optional) | Integer | A valid positive integer number including 0 value. | Specifies the minimum interval with which the client application may poll the ECS to refresh the current ServiceStatus using the AcquireConfiguration request.<br>This parameter will be present only when ServiceStatus=2-ACTIVATING.<br>If parameter is not present or value=0, this polling procedure is not triggered and ODSA App will keep waiting for any external action to continue the flow.<br>The maximum number of AcquireConfiguration requests before sending a ServiceStatus= 4 - DEACTIVATED, NO REUSE will be defined as an ECS configuration variable (MaxRefreshRequest) |
| PollingIntervalUnit<br>(Optional) | Integer | 0 – minutes<br>1 – seconds<br>2 – deciseconds | Specifies the time unit for the PollingInterval parameter. If this parameter is not present, 0 – minutes will be considered as default value |
| DownloadInfo<br>(Conditional) | Structure | multi-parameter value - see 4 for details | Specifies how and where to download the eSIM profile associated with the device.<br>Present in case the profile is to be downloaded at this stage. |
| CompanionDeviceInfo<br>(Conditional) | Structure | multi-parameter value – see Table 44 for details | Includes all information collected by the ES of the companion device. |
| MSG<br>(Optional) | Structure | multi-parameter value – see Table 45 for details | Includes information to be communicated and displayed to the user.  Only present if the PrimaryConfiguration parameter is present. |

Table 43. Companion and Primary Configuration for Acquire Configuration ODSA Operation

| “Companion device info” informational parameters | Type | Values | Description |
| --- | --- | --- | --- |
| CompanionTerminalFriendlyName<br>(Mandatory) | String | Any string value | User-friendly identification for the companion device which can be used by the Service Provider in Web Views. |
| CompanionTerminalVendor<br>(Mandatory) | String | Any string value | Manufacturer of the companion device. |
| CompanionTerminalModel<br>(Optional) | String | Any string value | Model of the companion device. |
| CompanionTerminalEid<br>(Optional) | String | Value following eUICC format | eUICC identifier (EID) of the companion device being managed |
