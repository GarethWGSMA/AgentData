## 14.2.2 Discovering 3rd party application information callflow

- Necessary preconditions for this use case:
1. ECS and App Backend exchange information for App_token generation. App Backend delivers App token to 3rd party application installed in the device.

The workflow then follows as described in Figure 66:

301. The 3rd party App provides the App token to the TS.43 client of the device to request 3rd party application information.
302. The TS.43 client initiates the EAP-AKA authentication procedure with the ECS, using app_ID ap2015. Device and ECS perform EAP-AKA authentication as described in section 2.8.1.
303. Client requests 3rd party application information by using Get3PAppInfo operation providing App_token as input attribute.
304. The App_token is used by the ECS to obtain the application information associated to the application backend (server).
305. ECS sends Get3PAppInfo response, including 3pAppNameAnon.
306. 3rd party application information managed by the operator can be used in the device.
