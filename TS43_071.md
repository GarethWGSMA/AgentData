## 6.2 ODSA Request Parameters

| New GET parameters for ODSA application | Type | Values | Description | Description |
| --- | --- | --- | --- | --- |
| operation | String | CheckEligibility ,<br>ManageSubscription,<br>ManageService,<br>AcquireConfiguration,<br>AcquirePlan,<br>AcquireTemporaryToken,<br>GetPhoneNumber,<br>VerifyPhoneNumber, GetSubscriberInfo | Indicates the operation requested by the “ODSA for eSIM device” application | Indicates the operation requested by the “ODSA for eSIM device” application |
| operation_type | Integer | Used by the ManageSubscription operation. | Used by the ManageSubscription operation. | Used by the ManageSubscription operation. |
| operation_type | Integer | 0 - SUBSCRIBE | to activate a subscription for the eSIM device. | to activate a subscription for the eSIM device. |
| operation_type | Integer | 1 - UNSUBSCRIBE | to cancel a subscription for the eSIM device. | to cancel a subscription for the eSIM device. |
| operation_type | Integer | 2 – CHANGE SUBSCRIPTION | to manage an existing subscription on the eSIM device. | to manage an existing subscription on the eSIM device. |
| operation_type | Integer | 3 – TRANSFER SUBSCRIPTION | to transfer a subscription from an existing device (with physical SIM or eSIM) to the eSIM device | to transfer a subscription from an existing device (with physical SIM or eSIM) to the eSIM device |
| operation_type | Integer | 4 – UPDATE SUBSCRIPTION | to inform the network of a subscription update on the eSIM device | to inform the network of a subscription update on the eSIM device |
| operation_type | Integer | 5 – ACTIVATE TERMINAL ICCID | to inform the network that the terminal_iccid or companion_terminal_iccid which is in a ServiceStatus DEACTIVATED state can be moved to an ACTIVATED state | to inform the network that the terminal_iccid or companion_terminal_iccid which is in a ServiceStatus DEACTIVATED state can be moved to an ACTIVATED state |
| operation_type | Integer | 6 – DEACTIVATE TERMINAL ICCID | to inform the network that the terminal_iccid or companion_terminal_iccid which is in a ServiceStatus ACTIVATED state can be moved to a DEACTIVATED state | to inform the network that the terminal_iccid or companion_terminal_iccid which is in a ServiceStatus ACTIVATED state can be moved to a DEACTIVATED state |

| operation_type | Integer | Used by the ManageService operation. | Used by the ManageService operation. | Used by the ManageService operation. |
| operation_type | Integer | 10 – ACTIVATE SERVICE | Indicates this is a request to activate a service on the eSIM device. | Indicates this is a request to activate a service on the eSIM device. |
| operation_type | Integer | 11 – DEACTIVATE SERVICE | Indicates this is a request to deactivate a service on the eSIM device. | Indicates this is a request to deactivate a service on the eSIM device. |
| operation_targets | String | Used by the AcquireTemporaryToken operation. | Used by the AcquireTemporaryToken operation. | Used by the AcquireTemporaryToken operation. |
| operation_targets | String | Comma separated list of the operation field found in this table | To acquire a temporary token associated with the ODSA operation(s) and AppID. | To acquire a temporary token associated with the ODSA operation(s) and AppID. |
